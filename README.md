# AGENT-ON

Panel de gestión de locales de Linmanía.

## Funciones

- Consulta y edición de locales.
- Filtros por agente y tipo de local.
- Clasificación automática entre Competición y Mueble.
- Gestión de agentes y modelos de máquinas.
- Conteo de unidades instaladas por modelo.
- Importación de locales desde Excel (.xlsx/.xls) y CSV.
- Plantilla de importación descargable.

## Importación

Las columnas obligatorias son:

- ESTABLECIMIENTO
- AGENTE
- MAQUINAS

Para indicar varias máquinas en un local, separa los modelos con una barra vertical:

```text
TSUNAMI | TSUNAMI | CONNECTION
```
